## 📊 计算方法

### 中国稿费税率规则

根据《中华人民共和国个人所得税法》规定：

1. **应纳税所得额计算**
   - **收入≤4000元**：应纳税所得额 = 稿费收入 - 800元
   - **收入＞4000元**：应纳税所得额 = 稿费收入 × (1 - 20%)

2. **税额计算**
   - 应纳税额 = 应纳税所得额 × 20%
   - 实际缴税额 = 应纳税额 × (1 - 30%)（稿酬所得减征30%）

3. **最终到手金额**
   - 实际到手金额 = 稿费收入 - 实际缴税额

### 示例计算

**案例1：单人3000元稿费**
```
稿费：3000元
应纳税所得额：3000 - 800 = 2200元
应纳税额：2200 × 20% = 440元
减征税额：440 × 30% = 132元
实际缴税：440 - 132 = 308元
实际到手：3000 - 308 = 2692元
到手比例：89.7%
```

**案例2：单人5000元稿费**
```
稿费：5000元
应纳税所得额：5000 × 80% = 4000元
应纳税额：4000 × 20% = 800元
减征税额：800 × 30% = 240元
实际缴税：800 - 240 = 560元
实际到手：5000 - 560 = 4440元
到手比例：88.8%
```

## ⚙️ 自定义配置

### 修改税率设置
编辑 `script.js` 文件中的 `TAX_CONFIG` 对象：

```javascript
const TAX_CONFIG = {
    THRESHOLD: 4000,        // 阈值（元）
    DEDUCTION_LOW: 800,     // 低收入扣除额（元）
    DEDUCTION_RATE: 0.2,    // 高收入扣除率（20%）
    TAX_RATE: 0.2,          // 税率（20%）
    REDUCTION_RATE: 0.3     // 减征率（30%）
};
```

### 修改界面样式
编辑 `style.css` 文件中的CSS变量：

```css
:root {
    --primary-color: #3498db;    /* 主色调 */
    --secondary-color: #2ecc71;  /* 次要色调 */
    --font-family: 'Noto Sans SC', sans-serif; /* 字体 */
    /* ... 其他变量 */
}
```

### 添加新功能
在 `script.js` 中添加新的JavaScript函数：

```javascript
// 示例：添加分享功能
function shareResult() {
    if (!currentResult) return;
    const text = `我计算了稿费扣税：${currentResult.amount}元稿费，实际到手${currentResult.netIncome}元！`;
    if (navigator.share) {
        navigator.share({
            title: '稿费扣税计算结果',
            text: text,
            url: window.location.href
        });
    } else {
        // 备用方案
        prompt('复制分享内容：', text);
    }
}
```
