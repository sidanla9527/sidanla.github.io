📦 项目简介

这是一个基于中国稿费税率计算方法的网页版扣税计算器，具有以下特点：

  • 完全免费 - 无任何费用，开源项目
  • 无需安装 - 只需一个浏览器
  • 跨平台 - 支持Windows、Mac、Linux、手机、平板
  • 无需网络 - 所有计算在本地完成
  • 数据安全 - 所有数据保存在本地浏览器中

🔧 详细部署步骤

方式一：直接双击运行

# 1. 将整个文件夹复制到任意位置 # 2. 双击 index.html 文件 # 3. 浏览器会自动打开 # 4. 开始使用！

方式二：使用Python搭建简单服务器

# 打开终端/命令提示符 cd /path/to/稿费扣税计算器_网页版 # Python 3.x python -m http.server 8000 # Python 2.x python -m SimpleHTTPServer 8000 # 然后在浏览器中访问： # http://localhost:8000

方式三：使用Node.js快速部署

# 1. 安装 Node.js # 2. 安装 serve 工具 npm install -g serve # 3. 启动服务 serve . # 4. 访问提示的网址
注意：如果出现跨域问题，建议使用本地服务器方式运行。直接双击打开可能会有部分功能限制。

  • 离线使用 - 无需网络连接
  • 跨平台 - Windows, Mac, Linux, iOS, Android
  • 轻量级 - 总文件大小 < 40KB
